# 🐶 Image Classification Project

## 📌 Project Description

This project is an image classification system using Artificial Intelligence and Deep Learning.

The project uses a trained machine learning model to classify images into predefined categories. A new image is uploaded and passed through the model to predict its class and confidence level.

The project was implemented using Google Colab, Python, TensorFlow, and Keras.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Use Artificial Intelligence for image classification.
- Load and run a trained image classification model.
- Upload and test a new image.
- Predict the image class.
- Display the prediction confidence.

---

## 🛠️ Technologies Used

---

## 📂 Project Files

The project contains the following files:

- keras_model.h5 — Original trained model.
- keras_model_fixed.h5 — Fixed model used for image classification.
- labels.txt — Contains the image classification labels.
- testt3.jpg — Test image.
- converted_keras (3).zip — Compressed model files.
- Google Colab Notebook — Contains the Python code used to load the model and classify images.

---

## ⚙️ How the Project Works

1. Install and import the required libraries.
2. Load the trained Keras model.
3. Read the class labels from labels.txt.
4. Upload a test image.
5. Resize the image to the required input size.
6. Convert the image into a numerical array.
7. Pass the image to the trained model.
8. Get the predicted class.
9. Display the predicted class and confidence percentage.
